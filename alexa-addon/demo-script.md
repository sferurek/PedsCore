# Alexa+ demo script — PedsCore AI

This is the short, reproducible flow to use in the Alexa+ simulator and later in the hackathon video.

## Demo 1 — Natural-language discovery

**User**

> Find a pediatric score for assessing croup severity.

**What this should demonstrate**

- Alexa+ understands the user's intent.
- Alexa+ calls `search_clinical_tools`.
- PedsCore, not the LLM, supplies the actual tool catalog result.

## Demo 2 — Structured tool inspection

**User**

> Show me the inputs needed for the Apgar score.

**What this should demonstrate**

- Alexa+ calls `get_clinical_tool`.
- Inputs and metadata come from the PedsCore catalog.
- The agent can guide the interaction without owning the clinical logic.

## Demo 3 — Deterministic calculation

**User**

> Calculate an Apgar score at five minutes. Heart rate 2, respiratory effort 2, muscle tone 2, reflex irritability 2, color 1.

**Expected result**

> Apgar score: 9 out of 10.

**What this should demonstrate**

- Alexa+ calls `calculate_clinical_score`.
- The numerical result is generated by deterministic PedsCore code.
- The same inputs produce the same result in the web app, MCP tests, remote smoke test, and Alexa+.

## Narration line for the video

> Alexa+ handles the conversation and chooses the right tool, while PedsCore keeps the clinical computation deterministic, inspectable, and reproducible.

## Do not use in the demo

- Real patient identifiers.
- Free-form treatment recommendations.
- Any claim that Alexa+ or PedsCore replaces clinical judgment.
- Any feature not actually implemented at recording time.
