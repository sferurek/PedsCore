# Alexa+ add-on scaffold

This directory intentionally contains `addon.template.json`, not a deployable `addon.json`.

Before Alexa AI CLI deployment:

1. copy the template to `addon-package/addon.json`
2. replace the remote MCP URL
3. replace privacy-policy and terms URLs with live HTTPS pages
4. publish the six required light-theme icon sizes
5. publish at least one 600x900 carousel image
6. run Alexa AI CLI validation/deployment

Do not rename this template to `addon.json` until every placeholder is replaced.
