- id: `prifle`

## Selected variant
Original Akcan-Arikan pediatric RIFLE modification.

Classification uses the worst criterion from:
- decline in estimated creatinine clearance (eCCl)
- urine output and duration

Loss and End-stage categories are only reported when persistent renal failure duration is explicitly supplied.

## Safety
Requires a credible baseline eCCl and correct urine-output timing. Classification is descriptive and does not generate renal-replacement or treatment recommendations.
