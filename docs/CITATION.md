# Citing and linking PedsCore

Canonical website: https://peds-core.vercel.app/

Source repository: https://github.com/sferurek/PedsCore

PedsCore includes a root `CITATION.cff` file so GitHub and compatible reference managers can expose machine-readable citation metadata.

When linking to a specific clinical tool, prefer its canonical localized URL, for example:

- Spanish: `https://peds-core.vercel.app/es/tools/<slug>`
- English: `https://peds-core.vercel.app/en/tools/<slug>`

For educational or technical references, link to the exact tool page when the subject is a specific score or calculator, and link to the project homepage when referring to PedsCore as a whole.
