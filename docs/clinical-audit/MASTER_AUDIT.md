# PedsCore Clinical Expansion Phase A — Master Audit

Audit date: 2026-09-12

Scope: the canonical 81-tool catalog at `main` before any Phase B implementation.

Method: repository reconstruction, reverse QA of every active calculator, review of existing evidence files, and targeted external verification against primary publications, validation studies, official datasets, and rights-holder terms. Facts, inferences, and unknowns are labelled in the detailed companion files.

## URGENT EXISTING IMPLEMENTATION REVIEW

These are audit findings, not corrections. Production behavior was not changed.

1. **SIPA — resolved in Batch 0A.** Forensic review of the original derivation (PMID 25638631) and prospective validation (PMID 27717564) confirmed strict thresholds `>1.22` (ages 4–6), `>1.0` (7–12), and `>0.9` (13–16). The implementation now uses precise half-open bands, raw-ratio classification, and rejects unsupported ages. See `SIPA_FORENSIC_REVIEW.md`.
2. **PRAM — required measurement condition absent (moderate/high consequence, major review).** The active calculator accepts any SpO₂ value, but published PRAM teaching material specifies a stable reading in ambient air; supplemental oxygen can suppress the oxygen component. The UI/input model does not encode or enforce that condition. Do not infer a treatment action from this finding.
3. **Apgar, Silverman-Andersen, Clinical Dehydration Scale, and FLACC — clinical descriptors absent (major review).** For most/all domains, the active catalog offers only `0 points`, `1 point`, `2 points`. The arithmetic is deterministic, but the application does not supply the observation-to-point definitions needed to calculate the instrument independently and safely.
4. **Apgar — uncovered output range and unverified bands (major review).** A score of 0–3 has no interpretation band. The catalog itself says final primary-source tracing is required while calculation is active. The 4–7 and 8–10 labels should be traced to the intended modern source and purpose, rather than inferred from the 1953 derivation paper.
5. **Active evidence metadata debt (evidence/reuse review).** Silverman-Andersen, CDS, FLACC, PECARN, the four QTc formulas, and bedside Schwartz remain marked internally as requiring final tracing or have no explicit reuse conclusion. SIPA closed this gate in Batch 0A. The remaining metadata debt does not by itself prove a formula error, but it is incompatible with declaring those implementations fully verified.

## Decision rules and score

- **GREEN — IMPLEMENT NOW:** definition, pediatric evidence, reuse and test path are sufficiently resolved for a Phase B implementation ticket. High-risk GREEN tools still require independent clinician review before activation.
- **YELLOW — IMPLEMENT WITH CONDITIONS:** viable only after the named condition is closed.
- **RED — BLOCKED:** evidence, definition, rights, data or safety blocker prevents implementation.
- **WHITE — DEFER:** valid or plausible, but currently redundant, superseded, niche, or disproportionate.
- Implemented tools receive `AUDIT ONLY`, because Phase A must not reconsider their activation state through this decision column.

Priority applies only to GREEN/YELLOW:

`utility + pediatric evidence + discoverability + category completion + simplicity + testability + reuse safety − clinical risk − ambiguity − maintenance burden`, each term scored 0–5. Maximum 35; negative values are possible. Component scores are in `IMPLEMENTATION_QUEUE.md`.

Abbreviations: `Def` definition completeness; `Impl` implementability; `Test` independent test-reference status; `OA` open access; `PD` public domain; `TBD` not established. Evidence grade: A strong, B moderate, C limited, D weak/uncertain.
