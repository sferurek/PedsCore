# PedsCore v0.1.0-alpha

Current public-alpha baseline · 19 September 2026.

PedsCore is an open-source bilingual library of pediatric and neonatal clinical tools with evidence traceability and no clinical-data persistence.

## Snapshot

- 137 cataloged clinical tools/surfaces.
- 134 active, 3 deprecated legacy surfaces.
- 0 active blocked surfaces and 0 local-planned entries.
- 64 implemented clinical products.
- 61 local-active calculation surfaces.
- Rights-limited instruments use official/original external references rather than dead-end blockers.
- WHO and CDC growth workflows operational.
- ES/EN production on Vercel.

Production: https://peds-core.vercel.app/
Repository: https://github.com/sferurek/PedsCore

## Safety

PedsCore is educational/informational support for qualified healthcare professionals. It does not diagnose, prescribe treatment or replace clinical judgment, local protocols or institutional policies. Do not submit identifiable patient information.

## Contributing

Clinical changes should provide an exact source/variant, licensing notes, safe wording and reproducible tests. See CONTRIBUTING.md and docs/EDITORIAL_POLICY.md.
